# ProQuiz Simulator — Urdu User Guide

**ProQuiz Simulator** mein khush amdeed! Yeh guide aapko software ke tamam
features samajhne aur apne muqablay ke imtehanat ki behtareen tayari ke liye
istemal karne mein madad degi.

## Software ke main tabs

Application ko aasani se istemal karne ke liye teen main tabs mein taqseem kiya
gaya hai:

1. **Home** — aapka dashboard. Yahan se aap apne pichle parhai ke session
   (MCQs aur Subjective dono) ko foran shuru kar sakte hain, apni majmui
   progress dekh sakte hain, aur software updates check kar sakte hain.
2. **MCQ Preparation** — Multiple Choice Questions (MCQs) ki practice ke liye
   tamam tools.
3. **Subjective Study** — tafseeli notes aur courses parhne ke liye.

## MCQ tab ko kaise istemal karein

Is tab mein aapki tayari ke liye chaar zabardast tools diye gaye hain.

> **Sab se pehla zaroori qadam: apna course select karein.**
> MCQ tab mein sab se upar aapko course select karne ka option nazar aayega.
> 1 Paper GK ke subjects ke liye **1 Paper MCQ GK** select karein. Special
> Education ke subjects ke liye pehle **Special Education** select karein.

### 1. Learn (study mode)

Yeh feature sawalat ko parhne aur yaad karne ke liye hai. Is mein sahi jawab
hamesha samne nazar aata hai.

1. **MCQ Preparation** tab par jayein aur apna main course select karein.
2. **Learn** ke button par click karein.
3. List mein se apna pasandeeda subject chunein.
4. Apna mode select karein: **Learn All Questions** (tamam sawalat parhein) ya
   **Learn by a Specific Range** (khas range ke mutabiq parhein).
5. Parhai shuru karne ke liye **Load MCQs** ka button dabayein.

### 2. Take a quiz

Is feature se aap quiz ki shakal mein MCQs ki practice kar sakte hain.

1. **MCQ Preparation** tab par jayein aur apna main course select karein.
2. **Take a Quiz** ke button par click karein.
3. Apna subject select karein.
4. Apni marzi ke options set karein:
   - **Timer** — quiz ke liye minutes mein time set karein (bina timer ke liye
     `0` likhein).
   - **Smart Mode** — agar yeh on hai to quiz ke doran diye gaye ghalat
     jawabat aakhir mein dobara pooche jayenge.
5. **Start Quiz** ka button dabayein.

### 3. Paste & create instant quiz

Agar aapke paas apne MCQs ki list hai, to aap is feature se fori tor par ek
aarzi (temporary) quiz bana sakte hain.

1. **MCQ Preparation** tab par jayein.
2. **Paste & Create Instant Quiz** ke button par click karein.
3. Apne sawalat ko copy kar ke text box mein paste karein.
4. **Start Quiz** ka button dabayein.

### 4. Mock exam generator

Yeh feature bilkul asal imtehan jaisa paper banata hai, jaisa ke PPSC ka 100
number ka paper hota hai.

1. **MCQ Preparation** tab par jayein aur apna main course select karein.
2. **Mock Exam Generator** ke button par click karein.
3. Apna pasandeeda option chunein:
   - **Default PPSC Settings** — 100 MCQs ka paper, jis mein subjects ki
     taqseem PPSC ke standard ke mutabiq hogi.
   - **Configure Manually** — apni marzi ka paper banayein, jis mein aap khud
     subjects aur unka tanasub (percentage) select kar sakte hain.

## Subjective Study tab ko kaise istemal karein

Yeh tab tafseeli mawad (study material) parhne ke liye hai.

### Misal: Special Education syllabus parhne ka tarika

1. Main menu se **Subjective Study** tab select karein.
2. **Syllabus for Special Education Teacher (VI)** ke button par click karein.
3. Agli screen par, pehle dropdown menu se **Subject** chunein (jaisa ke
   *Administration and management*).
4. Phir, doosre dropdown menu se us subject se mutaliq **Topic** chunein.
5. Ab chunein ke aap **poora subject** parhna chahte hain ya **makhsoos
   safhaat** (specific page range).
6. Parhna shuru karne ke liye **Load Content** ka button dabayein.

### Roman Urdu mein parhne ke liye

Jab content load ho jaye, to aapko heading ke neechay kuch buttons nazar
ayenge. Tarjuma dekhne ke liye **Show Roman Urdu** par click karein.

### Misal: Beginners English course parhne ka tarika

1. **Subjective Study** tab par jayein.
2. **Beginners English Learning Course** ke button par click karein.
3. Agli screen par, woh topic select karein jo aap seekhna chahte hain.
4. **Load Content** par click karein aur parhna shuru karein.

## Deegar zaroori features

- **Bookmarks** — dono study modes (MCQ aur Subjective) mein apni jagah
  mehfooz karne ke liye bookmark laga sakte hain.
- **Theme tabdeel karein** — light aur dark mode ke darmiyan tabdeel karne ke
  liye upar dayen kone mein mojood icon ka istemal karein.
