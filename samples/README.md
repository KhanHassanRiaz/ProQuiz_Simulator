# Code samples

These files are **illustrative, sanitized examples** of patterns used in
ProQuiz Simulator. They are not the production source, contain no real content
packs or credentials, and are intentionally small.

| File | Demonstrates |
| --- | --- |
| [`ipc-handlers.example.js`](ipc-handlers.example.js) | Allow-listed IPC with input validation |
| [`update-manager.example.js`](update-manager.example.js) | Public-repo auto-update flow |
| [`offline-cache.example.js`](offline-cache.example.js) | Content-addressed local cache |
| [`quiz-session.example.js`](quiz-session.example.js) | Quiz state, timer and scoring |

Run them with Node only where they make sense; the Electron examples require
an Electron host application. All examples are provided for reading and
evaluation under the repository [LICENSE](../LICENSE).
